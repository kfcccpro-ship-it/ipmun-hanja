### 1-3. 한자 학습 핵심
한 글자를 처음 학습할 때:
1. 큰글씨 획순 자동재생
2. 숫자 획순
3. 총 획수
4. 자동재생 완료 전 다음 단계 진행 불가
5. 표기는 `[옳을 가]`처럼 단순화
6. 5번 쓰기
   - 1~3칸: 숫자 획순 덮어쓰기
   - 1~3칸 완료 후 `[훈 음]` 2초 표시 + 메인 획순 엔진을 축소해 다시 재생
   - 4~5칸: 완전 자유쓰기
   - 정확한 획수에서만 3초 후 다음 칸
   - 한 획 되돌리기
7. 훈·음 직접 입력
8. 두 글자 조합, 뜻, 예문 학습

획순 기능은 보조가 아니라 **메인 학습 기능**이다.

3. GitHub Actions 최신 성공 여부 확인
4. UI를 함부로 전면 개편하지 않는다.
5. v0.24.0에서 완료된 통합검수:
   - **주간 10단어는 해당 주 start~end 안에서만 유효하며 다음 주에는 새 범위를 요구**
