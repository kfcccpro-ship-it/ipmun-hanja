### 1-3. 한자 학습 핵심
한 글자를 처음 학습할 때:
1. 큰글씨 획순 자동재생
2. 숫자 획순
3. 총 획수
4. 자동재생 완료 전 다음 단계 진행 불가
5. 표기는 `[옳을 가]`처럼 단순화
6. 5번 쓰기
   - 1~3칸: 숫자 획순 덮어쓰기
   - 1~3칸 완료 후 `[훈 음]` 2초 표시 + 메인 획순 엔진을 축소해 다시 재생
   - 4~5칸: 완전 자유쓰기
   - 정확한 획수에서만 3초 후 다음 칸
   - 한 획 되돌리기
7. 훈·음 직접 입력
8. 두 글자 조합, 뜻, 예문 학습

획순 기능은 보조가 아니라 **메인 학습 기능**이다.

## 5. 현재 핵심 운영 구조 — 반드시 유지

## A. 학습모드
사용자 정의:
- 부모가 **주 1회** 범위를 지정
- 교재 29~52쪽에서 **10단어 선택**
- 선택한 10단어는 그 주 동안 **매일 반복**
- 매일 같은 10단어를 기존 정규 학습모드로 수행
- 10단어 정규 학습 + 별도 500P 확인시험 완전통과 시 500P

현재 state:
- `weeklyPlan`
- 주간 10단어
- 해당 주 시작/종료일 저장
- 홈에서 "① 학습모드"로 표시

## B. 쪽지시험 대비모드
중요한 의미:
- 시험 대비 범위 시작점은 **항상 교재 29쪽**
- 부모는 "현재 학원 진도의 마지막 페이지 + 마지막 단어"만 지정
- 예: 현재 49쪽 세 번째 단어까지 진도라면
  - 시험대비 풀 = **29쪽 첫 단어부터 49쪽 세 번째 단어까지 전부**
- 현재 실제 진도는 약 49쪽
- 향후 3~4주 내 52쪽 끝까지 갈 예정
- 진도가 나갈수록 누적범위 자동 확장

현재 state:
- `quizProgress`
  - endPage
  - endWordId

매일 루틴:
- 누적범위 전체를 매일 다 쓰게 하지 않음
- 누적범위에서 **매일 20문제** 선정
- 우선순위:
  1. 오답
  2. 최근 학습 범위
  3. 기존 누적범위
- 매일 다시 섞음
- 한글→한자 중심
- `[훈 음]` 단서
- 힌트 1 = 앞 2획
- 힌트 2 = 앞 4획
- 직접 쓰기

- 완료 시 "오늘 쪽지시험 대비 완료"

현재 홈의 핵심:
1. **① 학습모드**
