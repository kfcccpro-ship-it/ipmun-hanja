# 실기기 검수 기준

## iPad
- Safari에서 실행
- Apple Pencil 1세대 사용
- 손가락/손바닥 입력이 필기로 남지 않는지 확인
- 빠른 연속 획에서 끊김 여부 확인
- 화면 회전 후 필기 유지 확인
- 20문제 연속 작성 확인

## Galaxy Tab
- Chrome에서 실행
- S Pen 사용
- 손가락/손바닥 입력 차단 확인
- 압력 변화와 선 굵기 확인
- 빠른 연속 획에서 끊김 여부 확인
- 20문제 연속 작성 확인

## 판정
실기기 검수 결과를 기준으로 선 굵기·압력 곡선·캔버스 높이를 조정합니다. 자동 브라우저 테스트 결과만으로 펜 품질을 확정하지 않습니다.
