# 장원한자 1단계 데이터 잠금 기준

## 범위
- 교재 인쇄 페이지 11~52쪽
- PDF 페이지 3~44쪽
- 인쇄 53쪽 이후는 1단계 범위에서 제외

## 본문편 11~26쪽
- 16개 페이지
- 페이지당 6개 한자어
- 총 96개 한자어
- 한자어/읽기/낱말풀이/낱말활용 예문을 원문 기준으로 입력
- 96/96 뜻 입력 완료
- 96/96 활용 예문 입력 완료

## 활·응편 29~52쪽
- 24개 페이지
- 페이지당 8개 한자 위치
- 총 192개 글자 위치
- 중복 제거 고유 한자 187자
- 각 위치에 글자/훈/음/부수/획수/페이지/연결 한자어를 입력
- 획수 192/192
- 훈 192/192
- 음 192/192
- 부수 192/192
- 본문 단어 연결 192/192

## 원본 우선 원칙
교재 표기가 데이터의 기준이다. 외부 사전 표기나 일반적인 이체자 표기로 임의 교정하지 않는다.

확인된 원문 보존 사례:
- 冰雪: 교재 글자 冰 사용
- 雪: 11획
- 考: 6획
- 祖: 훈 '할아비', 음 '조'
- 角度 활용문에 인쇄된 '90.角度...' 표기를 원문 필드에 보존
- 體溫 활용문에 인쇄된 '36~37.C' 표기를 원문 필드에 보존

## 프로그램 데이터
- data/meta.js: 96개 단어와 원문 뜻·활용문, 각 글자의 획수/부수/훈/음
- data/chars.js: 고유 한자 187자의 학습용 훈·음 인덱스
- 부모의 범위 입력은 PDF 페이지가 아닌 교재 인쇄 페이지를 사용

## 별도 보류
활·응편 하단의 작은 참고 한자어 묶음 및 확장 뜻열은 현재 핵심 학습 필드와 분리해 보류했다. 1단계 프로그램의 필수 학습 데이터인 한자, 훈, 음, 획수, 부수, 본문 단어, 뜻, 활용문에는 포함되지 않는다.
