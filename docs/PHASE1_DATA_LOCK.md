# 장원한자 1단계 데이터 잠금 기준

## 상태
**PHASE1_LOCKED - 교재 인쇄 52쪽까지 1단계 데이터 입력·대조 완료**

## 범위
- 기준: PDF 페이지가 아니라 **교재에 인쇄된 페이지 번호**
- 교재 인쇄 11~52쪽
- PDF 3~44쪽
- 인쇄 53쪽 이후는 1단계 범위에서 제외

## 본문편 11~26쪽
- 16개 페이지
- 페이지당 6개 한자어
- 총 **96개 한자어**
- 한자어 96/96
- 읽기 96/96
- 낱말풀이 96/96
- 낱말활용 예문 96/96
- 본문 페이지와 활·응편 글자 위치 연결 96/96

## 활·응편 29~52쪽
- 24개 페이지
- 페이지당 8개 한자 위치
- 총 **192개 글자 위치**
- 중복 제거 **고유 한자 187자**
- 글자 192/192
- 훈 192/192
- 음 192/192
- 부수 192/192
- 획수 192/192
- 교재 참고 한자어 목록 192/192
- 교재 확장 뜻열 192/192
- 본문 한자어 연결 192/192
- 누락 0

중복 한자 5자는 출현 위치를 모두 보존한다.
- 直
- 園
- 藥
- 禮
- 品

## 원본 우선 원칙
교재 스캔의 인쇄 표기를 데이터 정본으로 사용한다. 외부 사전·일반 표기와 다르더라도 임의로 바꾸지 않는다.

확인된 원문 보존 사례:
- 冰雪: 교재 글자 **冰**
- 雪: **11획**
- 考: **6획**
- 祖: **할아비 조**
- 角度 활용문과 體溫 활용문 등 교재 특유의 인쇄 표기는 원문 필드에 그대로 보존

## 프로그램 탑재
- `data/meta.js`: 96개 한자어, 읽기, 낱말풀이, 활용문, 글자별 핵심 정보
- `data/chars.js`: 187자 학습용 훈·음 인덱스
- `data/ref-29-34.js`
- `data/ref-35-40.js`
- `data/ref-41-46.js`
- `data/ref-47-52.js`: 교재의 참고 한자어 목록과 확장 뜻열
- `data/phase1-lock.js`: 런타임 1단계 잠금 상태 및 검수 수치

학습 화면에서는 참고 한자어·확장 뜻을 기본 화면에 과도하게 노출하지 않고 **'교재 참고 보기' 접이식 영역**으로 제공한다.

## 획순 그림 처리
활·응편에는 획순 그림이 존재한다. 1단계에서는 **교재의 획수와 표기 정보를 정확히 구조화**하고, 획순 그림을 임의로 벡터 획순으로 추정·변환하지 않는다. 실제 필기 평가는 교재 획수와 Apple Pencil/S Pen의 펜다운 횟수를 이용한다.
