# v0.31.0 - 교재 낱말 모음 + B안 3단계 평가·용돈

## 설계 기준

- 사용자: 초등학교 4학년. Apple Pencil/S Pen 필기 위주, 부모 수기 O/X 채점.
- 최초 학생 화면은 **학습 / 테스트** 두 가지로 유지.
- 학습과 테스트에 들어가면 **교재 한자 옆 작은 두 글자 낱말 모음**이 항상 첫 번째 카드.
- 두 글자 모음은 **부모가 학습용, 평가용을 독립적으로 ON/OFF**. 초기값: 양쪽 켜짐.
- 기존 5일 학습(500P), 예문, 획순과 기존 시험은 삭제하지 않음.

## 교재 자료

- 원본: `장원한자.pdf`, **인쇄 29~52쪽**(PDF 21~44쪽).
- 기본 2글자 단어 96개, 글자 192위치 / 고유 글자 187개.
- 교재 각 한자 옆 작은 칸은 `data/ref-29-34.js` ~ `data/ref-47-52.js`의 `CHAR_INFO[ch].referenceTerms`에 정리돼 있음.
- 이중 **정확히 한자 2글자**인 관련어만 학습·평가에 사용: 범위 전체 기준 중복 없는 **1,154단어**, 원본 항목 발생 수는 1,358개.
- 교재의 작은 한자어 목록에는 별도의 **한글 독음이 인쇄되어 있지 않음**. `assets/v31-term-readings.js`의 187자 메타 음 + 추가 194자 음 + 첫머리 두음법칙 일부 + 읽기 예외 + 원문 기본단어 96개 읽기를 이용하여 학습용 독음을 구성함.
- 구성한 읽기를 교재에서 검증한 표기로 소개하면 안 됨. 부모가 **낱말 읽기** 탭에서 특정 읽기를 직접 수정 가능. 수정 기록은 `db.hanja31.overrides`에 보존됨.
- 교재 어휘를 임의로 바꾸지 않으며 3~4글자 파생어는 이번의 '두 글자 모음'에서는 제외.

## 학생 사용법

### 학습 > 맨 첫 카드: 교재 두 글자 낱말
1. 해당 교재 페이지(부모가 정한 범위 내)를 선택.
2. 큰 한자 하나를 중심으로 옆의 관련 2자어 기본 6개 표시.
3. 낱말 터치 -> 한글 읽기 공개 및 한국어 TTS(지원 기기).
4. '다른 낱말도 보기'에서 해당 한자에 등록된 목록 전체 공개.
5. 다음 한자로 이동. 이후 기존 획순·훈음·5번 쓰기 중심 학습.

### 테스트 > 맨 첫 카드: 낱말 읽기 쪽지시험
- 기본 5문제, 부모가 3/5/6/8/10문제 선택 가능.
- 시험범위 마지막 쪽 중심 / 지정 범위 전체 중 선택.
- 한자를 보고 한글 읽기를 **직접 필기**(읽기 능력만 평가).
- 부모 O/X 후 80% 이상 통과. 보너스 0원이 기본(선택 지급 가능), 3단계 통과를 막지는 않음.

### B안 3단계(기본)

| 단계 | 기본 문제 수 | 문제 유형 | 채점 | 통과 기준 | 용돈 |
|---|---:|---|---|---|---:|
| 1 | 6 | 한자 1글자의 음 객관식 | 자동 정오 | 80% | 50원 |
| 2 | 8 | 훈·음 한글 쓰기 + 두 글자 한자어 쓰기 | 부모 O/X | 80% | 300원 |
| 3 | 6 | 부수 객관식 + 총 획수 숫자 쓰기 | 객관식 자동, 필기는 부모 O/X | 80% | 150원 |

- 미통과 시 **틀린 문항만 재시험**, 통과 시 다음 단계 열림.
- 객관식은 실제 가능한 정답/오답에서 2~4개 구성.
- **같은 날 같은 단계는 한 번만 적립**, 기본 일일 상한 500원.
- 돈은 앱 안의 **용돈 장부** 기록일 뿐 실제 송금이나 출금 기능은 없음.
- 기존 학습 보상 **500P**는 종전과 별개(1P = 1원 아님).
- 부모는 용돈 장부에서 실제 용돈을 지급했을 때 '지급했어요' 표시 가능.

## iPad 안정성 보완

- `index.html`의 필기 `makePad`: 이전 답안 PNG를 다시 불러오면 **배경 이미지(savedRaster)**로 유지. 이후의 '한 획 되돌리기'가 이전 답안을 통째로 지우는 문제 방지.
- 지우기 전체는 savedRaster도 삭제. 과거 저장 획의 개별 벡터 경로는 원본에 없으므로 과거 획 한 개만 지우는 기능은 지원하지 않으며 안내문 표시.
- v31 필기 시험은 상단 홈·부모 모드, 화면 숨김·pagehide 시 답안 스냅샷 보존을 시도.
- 펜 전용 모드, 단일 pointerId 포인터 캡처, touch-action:none, 손바닥 입력 필터, 캔버스 내 블록 선택 방지 유지.
- 세로/가로 반응형 CSS. iPad Safari·Apple Pencil 실기기 검증은 별도 필요.
